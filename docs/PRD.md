# 마이링크 (MyLink) - 제품 요구사항 정의서 (PRD)

## 1. 프로젝트 개요
- **프로젝트명**: 마이링크 (MyLink)
- **목적**: 사용자가 여러 개의 링크를 하나의 통합된 웹페이지로 관리하고 공유할 수 있는 링크 통합/멀티 링크 서비스 제공 (링크트리 클론 서비스).
- **대상 사용자**: 
  - 다양한 채널(SNS 텍스트, 유튜브 설명란 등)에서 다수의 링크를 효율적으로 홍보하고자 하는 크리에이터 및 인플루언서
  - 포트폴리오, 이력서 등 본인의 정보를 하나의 패키지로 엮어 보여주고 싶은 프리랜서 및 구직자
  - 오프라인 행사 시, 혹은 명함에 기재할 하나의 통합 웹 연락망이 필요한 일반 사용자

## 2. 핵심 기능 목록

### 🔴 필수 기능 (Must-have)
1. **사용자 인증**: 이메일 및 비밀번호 기반 로그인/회원가입
2. **프로필 관리 기능**: 닉네임, 간단한 소개글, 프로필 이미지 설정
3. **링크 관리 기능 (기본 텍스트형 블록)**: 사용자 링크 생성/수정/삭제/순서 이동
4. **소셜 미디어(SNS) 전용 아이콘 영역**: 각 SNS 연동 링크 전용 아이콘 배치 영역
5. **사용자 배경 테마 설정**: 프로필 화면의 배경색이나 배경 이미지를 변경하는 커스텀 기능

### 🟡 추가 및 고급 기능 (Nice-to-have)
1. **방문자 및 클릭 통계 분석 대시보드 (그래프 시각화 포함)**
2. **실시간 레이아웃 프리뷰 (Live Preview)**

## 3. 각 기능의 상세 설명

### 3.1 사용자 인증 (Authentication)
- **회원가입/로그인 (이메일 기반)**: 이메일과 지정된 비밀번호를 이용하여 회원가입 및 로그인 절차를 진행합니다.
- **고유 URL 생성**: 가입 시 사용자가 개인 식별 용도로 사용할 고유 ID를 설정 (`/username`).

### 3.2 프로필 관리 (Profile Management)
- **이미지 업로드**: 프로필 상단에 로드될 대표 프로필 이미지 업로드 기능 제공.
- **기본 정보 설정**: 해당 프로필에 접속했을 때 나타날 계정명(닉네임)과 한 줄 자기소개(Bio) 작성 기능.

### 3.3 링크 블록 관리 (Core Link Management)
- **기본 텍스트 링크 버튼**: 텍스트(제목) 및 목적지(URL)를 입력하여 기본 포맷의 텍스트형 링크 버튼을 무제한으로 생성.
- **파비콘(Favicon) 자동 적용**: 링크의 URL을 입력하면 해당 타겟 웹사이트의 파비콘 이미지를 추출하여 텍스트 버튼 좌측 아이콘으로 자동 렌더링.
- **CRUD 기능 지원**: 작성된 링크 정보에 대해 관리 페이지 내에서 언제든 수정, 삭제 가능.
- **Drag & Drop 정렬 기능**: 생성한 링크 목록을 사용자가 마우스로 드래그하여 직관적으로 배치 순서를 조정.
- **버튼 공개 토글 (활성화/비활성화)**: 일시적으로 숨기고 싶은 링크를 삭제하지 않고 잠시 꺼둘 수 있는 공개/비공개 토글 스위치 제공.

### 3.4 SNS 아이콘 연결 영역 (Social Links)
- **플랫폼 전용 아이콘 표시**: 인스타그램, 유튜브, 깃허브, 트위터(X), 링크드인 등 자주 쓰는 연락 수단을 URL만 입력하면 해당 플랫폼의 전용 아이콘으로 변환하여 노출.
- **효율적인 공간 배치**: 직사각형의 큰 텍스트 블록 상단 혹은 하단에 동그랗고 조그마한 별도의 가로 배치 구역을 편성하여 레이아웃을 간결하게 유지.

### 3.5 배경 테마 설정 (Background Customization)
- **배경(Background) 커스터마이징**: 
  - 단순 단색(Solid Colors) 모드, 2컬러 이상의 그라데이션 모드, 또는 사용자 지정 배경 이미지 업로드(Image background) 기능.
  - *참고: 깔끔하고 통일된 디자인을 제공하기 위해 폰트 및 버튼 모양 스타일링 등 기타 상세 커스텀은 지원하지 않고 배경 변경만 제공합니다.*

### 3.6 실시간 통계 대시보드 (Analytics with Charts)
- **트래픽 분석 데이터 제공**: 내 프로필 누적 방문자 수, 개별 링크 버튼의 클릭 수 등 핵심 트래픽 분석 데이터 수집.
- **통계 그래프 차트 도입**: 수집된 데이터를 바탕으로 주간, 월간 트렌드를 시각적으로 알아보기 쉽게 **선 그래프(Line Chart)** 혹은 **막대 그래프(Bar Chart)** 형태로 렌더링.
