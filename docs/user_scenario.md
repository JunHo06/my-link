# 마이링크 (MyLink) - 사용자 시나리오 (User Scenarios)

아래 시나리오는 서비스의 핵심 사용자층인 **1) 방문자**와 **2) 마이링크 소유자(크리에이터)** 두 그룹의 주요 행동 흐름을 바탕으로 작성되었습니다.

---

## 1. 방문자 (Visitor) : 마이링크 프로필 방문 과정

- 사용자는 **특정인의 다방면적인 온라인 활동과 정보를 한눈에 파악하기 위해** 인스타그램, 유튜브 등에 기재된 마이링크(MyLink) URL을 클릭하여 페이지에 접속한다.
- 사용자는 **본인이 가장 관심 있는 콘텐츠나 외부 운영 사이트로 직행하기 위해** 화면 중앙에 큼지막하게 배치된 **텍스트 링크 버튼**을 클릭한다.
- 사용자는 **해당 버튼을 눌렀을 때 어떤 웹사이트로 연결될지 직관적으로 예측하기 위해** 텍스트 버튼 좌측에 표시된 **파비콘(Favicon)** 이미지를 먼저 확인한다.
- 사용자는 **해당 크리에이터와 소통하거나 또 다른 개인 플랫폼을 방문하기 위해** 링크 목록과는 별도로 깔끔하게 묶여 배치된 **소셜 미디어(SNS) 아이콘 영역**의 로고를 터치한다.
- 사용자는 **마음에 든 이 프로필 장표를 자신의 지인들에게도 소개해주기 위해** 화면 우측 상단에 위치한 **'공유하기'** 버튼을 클릭하여 URL을 복사한다.

---

## 2. 소유자 (Owner) : 링크 추가/수정/삭제 등 관리 과정

### 2.1 링크 추가 (Add)
- 사용자는 **나의 새로운 포트폴리오나 웹사이트를 방문자들에게 새롭게 홍보하기 위해** 관리자 대시보드 화면상에서 **'새 링크 추가'** 버튼을 누른다.
- 사용자는 **방문자가 해당 링크의 역할을 명확하게 알 수 있게 유도하기 위해** 생성된 블록의 '제목(Title)' 필드와 '목적지 주소(URL)' 필드에 각각 알맞은 정보를 타이핑한다.
- 사용자는 **URL 형식을 실수로 잘못 입력하여 접속이 안 되는 불상사를 방지하기 위해** "올바른 URL 형식(https://)을 입력해 주세요"라는 오류 알림 피드백을 확인하고 주소를 고쳐 적는다.

### 2.2 링크 수정 및 배치 변경 (Edit & Reorder)
- 사용자는 **과거에 등록해 둔 웹페이지의 접속 주소가 달라진 것을 업데이트하기 위해** 해당 링크 블록의 내용 텍스트를 클릭하여 새로운 주소를 덮어씌운다.
- 사용자는 **내가 방금 변경한 제목이나 아이콘이 실제 스마트폰 화면에서 어떻게 보이는지 즉시 확인하기 위해** 관리자 화면 우측에 항상 고정되어 있는 **'실시간 레이아웃 프리뷰'** 시뮬레이터 화면을 살펴본다.
- 사용자는 **이벤트가 끝난 링크를 당분간 방문자에게서 숨기기 위해** 삭제하는 대신 해당 링크 블록 우측의 **'공개 토글 스위치'**를 눌러 비활성화 기능으로 전환한다.
- 사용자는 **가장 최근에 출시된 핵심 상품 사이트를 메뉴 최상단에 올려두기 위해** 해당 링크 블록의 좌측 핸들(점 6개 아이콘)을 마우스로 잡고 맨 위쪽으로 **드래그 앤 드롭(Drag & Drop)**하여 수직 정렬 순서를 조정한다.

### 2.3 링크 삭제 (Delete)
- 사용자는 **더 이상 유효하지 않게 된 옛날 블로그 링크를 완전히 파기하기 위해** 해당 링크 블록 구석에 있는 **'삭제하기(휴지통 아이콘)'** 버튼을 누른다.
- 사용자는 **중요한 링크를 삭제 버튼 오류 터치로 날려버린 것을 빠르게 복구하기 위해** 삭제 직후 화면 하단에 3~5초간 잠시 나타나는 팝업 알림의 **'실행 취소(Undo)'** 버튼을 다급히 클릭한다.
